# NovostnikAllertBot — ретранслятор с двумя ветками (MAX → MAX)

Бот-подписчик опрашивает канал-источник в MAX и обрабатывает посты по двум
независимым веткам. Все прочие сообщения источника игнорируются.
Telegram не используется.

## Схема

```
MAX-канал источник (бот-подписчик)
        │   GET /messages  (опрос раз в 45 c)
        ▼
   классификация поста
        │
        ├─ РАКЕТНАЯ ОПАСНОСТЬ (объявление/отбой)
        │        └────► MAX-канал цель (форвард, при неудаче — копия)
        │
        ├─ УГРОЗА БПЛА («силами ПВО уничтожены N БПЛА…»)
        │        └─► рерайт gpt-5.6-luna (aitunnel.ru)
        │              └────► MAX-канал цель (HTML: жирный, «цитата», ссылка)
        │
        └─ остальное — игнор
```

## Триггеры

**Ракетная ветка** (строго два официальных формата):
- `внимание в калужской области объявлена ракетная опасность`
- `отбой ракетной опасности`

**Ветка БПЛА** — пост должен содержать ОБЕ подстроки:
- `пво уничтожен` (покрывает «ПВО уничтожены/уничтожен»)
- `бпла`

Сравнение регистронезависимое; эмодзи, пунктуация, переносы игнорируются, `ё`→`е`.

## Рерайт БПЛА (формат MAX)

Модель — `gpt-5.6-luna` (aitunnel.ru). Нейросеть возвращает только содержательные
части в JSON, а разметка и обязательная ссылка собираются детерминированно в коде
(`rewriter.py`). Итоговый пост:

```
⚡ <N БПЛА уничтожены ... силами ПВО над регионом>      (жирным)

Их сбили над <округа> округами, а также на окраине <города>.

<абзац деталей: повреждения, пострадавшие, эвакуация, помощь>   (0..N штук)

<абзац деталей>

«<абзац про оперативные группы>», - Владислав Шапша.

📍 Калуга, внимание (ссылка на канал)
```

**Полнота фактов.** Блок `details` — обязательное место для всего, что не влезло в
заголовок, лид и цитату: повреждения имущества, пострадавшие, эвакуация, отмена
занятий, обещанная помощь. Без него бот терял такие абзацы. Дополнительно код
сверяет числа исходника с числами готового поста: если хоть одно пропало,
рерайт бракуется и публикуется исходный текст целиком
(отключается `AI_REQUIRE_ALL_NUMBERS=0` — тогда только предупреждение в лог).

Цитата опциональна: если в исходнике нет абзаца про оперативные группы, пост
собирается без неё, а сведения уходят в `details`.

Если нейросеть недоступна или ответила мусором — публикуется исходный текст
(fallback).

## Файлы

| Файл | Назначение |
|------|-----------|
| `.env`          | **секреты** (токен MAX, ключ нейросети) — не в репозитории |
| `.env.example`  | шаблон `.env` |
| `config.py`     | каналы, триггеры, TLS, чтение `.env` |
| `matcher.py`    | нормализация и классификация постов (rocket/uav) |
| `rewriter.py`   | вызов GPT-4.1-mini и сборка MAX-поста |
| `max_api.py`    | HTTP-обёртка над API MAX |
| `parsing.py`    | разбор ответов MAX |
| `publishers.py` | публикация: ракеты→форвард; БПЛА→HTML-текст |
| `state.py`      | защита от повторной публикации |
| `bot.py`        | точка входа, классификация и цикл опроса |

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # Windows: copy .env.example .env
                       # затем вписать MAX_TOKEN и AI_API_KEY
python bot.py --seed   # один раз: пометить историю обработанной (НЕ публикует)
python bot.py --loop   # рабочий режим
```

Без `MAX_TOKEN` бот не стартует и скажет об этом. Без `AI_API_KEY` — работает,
но посты о БПЛА идут исходным текстом, без рерайта. На Windows есть
`run_loop.bat` (двойной клик).

Прочее: `--me` (токен), `--chats` (chat_id каналов), `--check` (сырой ответ),
`--once` (один проход), `--once --dry-run` (найти и отрерайтить, НЕ публикуя).
Логи: консоль + `bot.log` (UTF-8).

## TLS / сертификат MAX

В проекте лежит `russian_trusted_bundle.pem` (Russian Trusted Root+Sub CA,
скачаны с официального gu-st.ru) — используется по умолчанию, полная проверка
TLS работает на любой машине. aitunnel использует обычный сертификат.

## Безопасность

Секреты живут только в `.env` (в `.gitignore`) или в переменных окружения —
в коде и в репозитории их нет. Переменные окружения имеют приоритет над `.env`,
поэтому на сервере ключи можно задать в systemd-юните (`EnvironmentFile=`).

Токен MAX и ключ aitunnel когда-то передавались в открытом виде в переписке —
их стоит перевыпустить (@masterbot в MAX, личный кабинет aitunnel.ru) и вписать
новые в `.env`.
